# Resources

## iFIX (GE Vernova Proficy)

- [Free iFIX HMI/SCADA trial](https://gevernova.com/software/product-trials/ifix-hmi-scada): single-use download link by email; 2-hour restartable runtime; bundles IGS, Proficy Historian, Operations Hub
- [iFIX product page](https://www.gevernova.com/software/products/hmi-scada/ifix)
- [Getting Started with iFIX (2024 guide, PDF)](https://gevernova.com/software/documentation/ifix/version2024/pdf/Getting%20Started%20with%20iFIX.pdf)
- Paid courses (for later, if an employer sponsors): iFIX Fundamentals and iFIX Advanced, offered by GE Vernova and integrators

## OpenPLC

- [OpenPLC Project / Autonomy Logic](https://autonomylogic.com/): editor and runtime downloads, docs
- [OpenPLC + Arduino/ESP32 integration guide](https://plcprogramming.io/openplc/arduino-integration)
- [OpenPLC dashboarding example with Modbus register mapping](https://www.losant.com/blog/how-to-add-dashboarding-to-your-openplc-devices)

## ESP32 / Modbus

- Arduino library: **modbus-esp8266** by Alexander Emelianov (works on ESP32)
- Python: [pymodbus](https://pypi.org/project/pymodbus/)

## Standards worth knowing by name

- **IEC 61131-3**: PLC programming languages (Ladder, Structured Text, Function Block, SFC)
- **ISA-101**: HMI design
- **ISA-18.2**: alarm management
